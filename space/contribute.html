Community contribution portal

Submit an embedding

Upload one standardized gene-embedding package directly to the library-owned Hugging Face Dataset as a Pull Request.

Open Hugging Face uploader Download submission template Return to catalog

What you need

You need a Hugging Face account. You do not need a GitHub account, GitHub fork, personal Dataset, or commit SHA.

Prepare exactly one folder with a unique embedding ID: 

<embedding_id>/
├── embeddings.npz
├── genes.tsv
├── metadata.json
├── README.md
└── submission.yaml

The embedding ID must contain 3–80 lowercase letters, numbers, dots, underscores, or hyphens. It must begin with a letter or number.

Package contract

  • embeddings.npz contains exactly one two-dimensional array named embeddings.
  • The embedding matrix uses float32.
  • genes.tsv contains one unique, non-empty ensembl_gene_id column.
  • Gene-table rows correspond exactly to matrix rows.
  • metadata.json describes the stored embedding.
  • submission.yaml contains contributor, scientific, provenance, licensing, and attestation information.

Upload as a Pull Request

  1. Click Open Hugging Face uploader.
  2. Upload all five files under: 
    incoming/<embedding_id>/
  3. Add a descriptive message such as: 
    Submit <embedding_id>
  4. Select Open as a pull request.
  5. Do not commit the files directly to main.
  6. Confirm that the Pull Request is Open or Ready for review.

Command-line alternative

Uploading through the browser is the primary route. The equivalent command-line submission is: 

hf upload \
  embeddingsSSRF/gene_embeddings_staging \
  ./<embedding_id> \
  incoming/<embedding_id> \
  --repo-type dataset \
  --create-pr \
  --commit-message "Submit <embedding_id>"

Programmatic uploads may initially appear as Draft. Change the Pull Request status to Open or Ready for review before processing.

Catalog category

Recommended categories are:

DNA, Expression, Functional Genomics, Knowledge, Literature, Multimodal, Network, Protein, RNA, Regulatory, and Single-cell.

Matching is case-insensitive. Another submitted value is preserved but displayed under Other.

Privacy and publication

Do not upload personal email addresses, credentials, access tokens, patient information, patient-level data, or other sensitive material.

A strict validation PASS is centrally archived under: 

data/embeddings/<embedding_id>/

The registry and static catalog then link to this library-owned copy.

Staging access

This page currently targets the staging Dataset. While that Dataset is private, submission is limited to users who already have access to the organization repository.

The production button will target the public production Dataset after final approval.
