Submit directly through Hugging Face

A Hugging Face account is required. A GitHub account, GitHub fork, separate Dataset, and commit SHA are not required.

  1. Prepare one folder containing embeddings.npz, genes.tsv, metadata.json, README.md, and submission.yaml.
  2. Name the folder using a unique lowercase embedding ID.
  3. Click Open Hugging Face uploader and place the files under incoming/<embedding_id>/.
  4. Select Open as a pull request. Do not commit the files directly to main.
  5. Ensure the resulting Pull Request is marked Open or Ready for review, not Draft.
