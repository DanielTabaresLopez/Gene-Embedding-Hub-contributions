Automatic contribution workflow

  1. Put embeddings.npz, genes.tsv, metadata.json, and README.md in a public Hugging Face Dataset.
  2. Freeze the candidate at a full commit SHA.
  3. Add one submission YAML through a GitHub Pull Request.
  4. GitHub validates the frozen package. A strict PASS is merged and published automatically.
